# IconPark 插图

装饰图来自 [IconPark](https://iconpark.oceanengine.com/)（`@icon-park/svg` two-tone）。

- 许可：**Apache-2.0**
- 生成：`npm run icons:gen`（需已安装 `@icon-park/svg`、`sharp`）

| File | IconPark | Use |
|------|----------|-----|
| eyes.png | PreviewOpen | 预览空状态 |
| static.png | PictureOne | 静态图 |
| anim.png | Film | 动态图 |
| save.png | EmotionHappy | 确认保存 |
| warn.png | Attention | 积分不足 |
| ok.png | CheckOne | 成功 |
| ticket.png | Ticket | 兑换码 |
| search.png | Search | 按 ID 查询 |
| empty.png | Inbox | 空态备用 |
| guide.png | GuideBoard | 使用引导 |
| feedback.png | Mail | 意见反馈 |
| gift.png | Gift | 见面礼弹窗 |
| checkin.png | Calendar | 每日签到 |
