How to Add the Person Walking Emoji to Slack, Discord and Teams

Add it to Slack
  1. Click “Download GIF for Slack” above. That file is already under Slack’s 128 KB limit.
  2. In Slack, open the emoji picker in the message box and choose “Add Emoji”.
  3. Upload the GIF and name it :fluent-person-walking:, then save.
  4. Type :fluent-person-walking: in any message or reaction to use it.
Add it to Discord
  1. Download the GIF above. Discord emojis must be 256 KB or smaller.
  2. Open Server Settings → Emoji, then click “Upload Emoji” (you need the Manage Expressions permission).
  3. Pick the GIF and give it a name such as fluent_person_walking.
  4. Use it with :fluent_person_walking:. Animated emojis in messages may need Discord Nitro.
Add it to Microsoft Teams
  1. Download the GIF above.
  2. In a Teams chat, open the emoji picker and go to your organization’s custom emojis.
  3. Choose “Add” (+), upload the GIF, name it Person Walking, and save.
  4. It appears in the picker for everyone in your organization, if your admin allows custom emojis.
